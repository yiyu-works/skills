# 清晰产品文案


## 工作流程
先识别读者、发布场景、语言、原作者口吻与不可变事实。用户只要求局部调整时保留其余结构；未要求翻译时跟随原文语言。

先做信息编辑：让读者知道对象、动作、结果与条件。空泛形容词尽可能替换为已有事实；缺少证据时删掉夸张承诺，不编造数字。专业读者需要的术语保留，首次出现的陌生术语按需解释。

再做表达编辑：减少重复、过长前置修饰、没有主语的被动句；把操作写成具体动词。保留有效比喻与个人语气，不机械删除所有口语、转折或长句。标题承诺须由正文兑现。

比较改写前后的事实清单：产品名、数字及单位、时间、否定、条件、价格、许可、退款与维护范围。尤其不能把“可能”“测试中”“限定环境”改成保证成功、正式发布或永久支持。

使用 [事实保真检查](references/fidelity.md) 做最后核对。需要保留的引用和命令保持原样，代码不作为散文润色。输入包含敏感字段时避免在公开文案重复它们。

## 交付
默认给可直接使用的成稿，重大含义修改附简短说明。用户要对比时提供原句、改句与原因；资料不足的承诺列为待确认，不混入最终正文。
