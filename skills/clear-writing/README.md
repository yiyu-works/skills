# 清晰产品文案

## 使用

```text
使用 $clear-writing：把这段产品介绍改得自然清楚，保留价格、限制和作者语气。
```

## 安装

```bash
npx skills add yiyu-works/skills --skill clear-writing
```

也可将本文件夹完整复制到宿主的 skills 目录。见 [安装说明](../../docs/installation.md)。
