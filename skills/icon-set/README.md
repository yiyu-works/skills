# 统一风格图标集

icon-set · 免费实验版 0.1.0

## 使用

```text
使用 $icon-set：为任务管理工具制作六个统一风格图标，优先 SVG，检查24px下是否可辨认。
```

## 安装

```bash
npx skills add yiyu-works/skills --skill icon-set
```

也可将本文件夹完整复制到宿主的 skills 目录。见 [安装说明](../../docs/installation.md)。

## 依赖与范围

SVG路径不需要依赖；栅格生成需宿主图片工具；切图需Pillow。工作流程见 [SKILL.md](SKILL.md)。外部模型及付费服务的费用不包含在技能中。
