# 按任务选择状态
| 操作 | 必测结果 | 常见缺陷 |
|---|---|---|
| 搜索/分页 | 新查询结果对应新条件 | 旧请求覆盖新结果、选中项误归属 |
| 保存 | 服务端成功后读回相同对象 | toast成功但刷新丢失 |
| 提交失败 | 保留输入并可重试 | 清空输入、重复创建 |
| 空列表 | 区分无数据和筛选无结果 | 为筛选结果提供错误的新建路径 |
| 弹窗 | 打开/关闭/焦点返回 | 焦点丢失、关闭时丢未保存数据 |
| 窄屏 | 主要操作可见且可达 | 固定底栏遮挡、双滚动 |
严重级别按真实影响：数据破坏/主任务阻断/部分功能受损/表现问题。缺少复现条件时说明推断。
