# 前端状态与交互检查

frontend-check · 免费实验版 0.1.0

## 使用

```text
使用 $frontend-check：检查这个页面的表单、列表和弹窗，只报告可复现问题，暂时不要改代码。
```

## 安装

```bash
npx skills add yiyu-works/skills --skill frontend-check
```

也可将本文件夹完整复制到宿主的 skills 目录。见 [安装说明](../../docs/installation.md)。

## 依赖与范围

项目开发环境；浏览器交互工具；已有测试命令。工作流程见 [SKILL.md](SKILL.md)。外部模型及付费服务的费用不包含在技能中。
