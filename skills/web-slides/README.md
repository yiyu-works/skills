# 可编辑网页演示

web-slides · 免费实验版 0.1.0

## 使用

```text
使用 $web-slides：把这份产品介绍做成离线 HTML 演示，支持键盘翻页、备注和打印。
```

## 安装

```bash
npx skills add yiyu-works/skills --skill web-slides
```

也可将本文件夹完整复制到宿主的 skills 目录。见 [安装说明](../../docs/installation.md)。

## 依赖与范围

现代浏览器；PDF导出需浏览器打印；不提供原生PPTX导出。工作流程见 [SKILL.md](SKILL.md)。外部模型及付费服务的费用不包含在技能中。
