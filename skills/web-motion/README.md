# 网页交互动效

web-motion · 免费实验版 0.1.0

## 使用

```text
使用 $web-motion：为产品介绍页做滚动出场和阅读进度，保留减少动态效果与无 JS 的可读性。
```

## 安装

```bash
npx skills add yiyu-works/skills --skill web-motion
```

也可将本文件夹完整复制到宿主的 skills 目录。见 [安装说明](../../docs/installation.md)。

## 依赖与范围

浏览器；沿用项目技术栈；默认不需要生成API。工作流程见 [SKILL.md](SKILL.md)。外部模型及付费服务的费用不包含在技能中。
