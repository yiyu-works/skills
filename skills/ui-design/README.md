# 界面设计与探索

ui-design · 免费实验版 0.1.0

## 使用

```text
使用 $ui-design：为我的产品做一个可运行首页，遵循现有品牌，检查桌面和手机效果。
```

## 安装

```bash
npx skills add yiyu-works/skills --skill ui-design
```

也可将本文件夹完整复制到宿主的 skills 目录。见 [安装说明](../../docs/installation.md)。

## 依赖与范围

前端编辑能力；视觉验收需浏览器与图片查看工具。工作流程见 [SKILL.md](SKILL.md)。外部模型及付费服务的费用不包含在技能中。
