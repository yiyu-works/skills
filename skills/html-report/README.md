# 单页 HTML 报告

html-report · 免费实验版 0.1.0

## 使用

```text
使用 $html-report：把这些调研材料做成可离线阅读的 HTML 报告，区分事实、推断与建议。
```

## 安装

```bash
npx skills add yiyu-works/skills --skill html-report
```

也可将本文件夹完整复制到宿主的 skills 目录。见 [安装说明](../../docs/installation.md)。

## 依赖与范围

现代浏览器；无构建依赖。工作流程见 [SKILL.md](SKILL.md)。外部模型及付费服务的费用不包含在技能中。
