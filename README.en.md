# Yiyu Works · Skills

Ten free experimental Agent Skills for project documentation, interface design and content delivery.

Version 0.1.0 provides independently written workflows, editable offline templates and local helpers. Cross-model outcome evaluation is not complete. This project is not affiliated with oil-oil and contains no Oil UI Pro content.

```bash
npx skills add yiyu-works/skills --skill readme-polish
```

Or copy an individual folder from `skills/` to your agent's documented skill directory. Retain its references, assets and scripts.

See the [catalog](README.md), [installation](docs/installation.md), [compatibility](docs/compatibility.md), [validation results](evaluations/RESULTS.md) and [source notes](THIRD_PARTY_NOTICES.md).

Image generation, transcription and browser capabilities must be supplied by your agent. No hosted AI service or automatic publication is included. MIT applies to our original code and documentation, not to external inputs or media.
