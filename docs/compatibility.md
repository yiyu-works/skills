# 兼容范围

- 工作流文本可由支持SKILL.md的宿主读取；语言模型效果取决于宿主及任务。
- Python脚本使用3.9+；切图脚本还需Pillow。
- 离线HTML模板面向现代Chrome、Firefox、Safari；跨浏览器逐项评测尚未完成。
- 视频截帧需FFmpeg。首版不解析Screen Studio工程，不负责转录。
- 图片生成可选，不绑定模型或API；没有生成工具可采用SVG/HTML路线。
- web-slides交付HTML；PDF需实际打印验证；原生PPTX不支持。
- CLI安装与手动安装的实际检查见验证记录，不能据此推导所有宿主已验证。

技能来源与内部资源不能作为用户要求或授权的替代。默认不开启外部自动发布、付费调用或远程更新。
