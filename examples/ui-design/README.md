这是复现任务，不是客户案例或模型生成效果证明。

## 请求

```text
为我的产品做一个可运行首页，遵循现有品牌，检查桌面和手机效果。
```

## 输入与验收

# 测试任务
输入：中文预约产品、390px 与 1440px 视口、三段长标题、既有深绿品牌。
验收：品牌保留；内容和按钮未裁切；页面主动作明确；只交方案时不声称实现。
比较任务：用相同文案做两种不同布局，比较页能切视口、打开原页面。


使用自己的资料执行后，将输入来源、输出路径、宿主/模型版本与实际检查结果记入任务目录。不要将用户的敏感资料提交到公共仓库。
