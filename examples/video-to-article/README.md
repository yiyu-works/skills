# 视频转图文文章 示例

这是复现任务，不是客户案例或模型生成效果证明。

## 请求

```text
把视频和 SRT 转成教程文章，提取真实配图，并记录关键结论对应的时间点。
```

## 输入与验收

# 测试任务
输入：SRT含逗号毫秒，VTT含设置字段，字幕与视频中间被剪过。
验收：时间解析正确；不以统一偏移猜全片；文章数字有出处；配图逐张核对。
缺视频案例：可交文字初稿但不能标为图文实测通过。


使用自己的资料执行后，将输入来源、输出路径、宿主/模型版本与实际检查结果记入任务目录。不要将用户的敏感资料提交到公共仓库。
